# 两两偏好分析设计（`ranked-ballots-pairwise`）

本文说明新增的独立两两偏好分析链路：在同一份严格 `{candidates, ballots}`
契约上，为**每个无序候选对**累计精确整数表达权重，并由同一份完整矩阵推导
严格多数有向图、强连通分量与 Condorcet winner。它是只读的一次性分析，**不
替代** IRV 计票（`ranked-ballots`）与纸票抽核（`ranked-ballots-audit`），也
不修改归档库或任何既有结果。

## 1. 范围与边界

- 输入为 UTF-8 严格 JSON（最多 8 MB，沿用 `common.read`：拒绝重复键、非有限
  数值），顶层恰为 `candidates`、`ballots`；候选 1..100 个互不重复的合法 ID，
  票组至多 20000，每项恰为 `{id, ranking, weight}`，ranking 长度 0..100、
  组内不重复且均属于 candidates，weight 为 1..10^9 整数。空票组列表有效。
- 输出为普通 JSON，原子替换；输入/输出解析后同路径或输出为符号链接即拒绝；
  任何输入、校验或计算失败退出 2 并保留既有输出字节。
- 所有累计值为精确整数（20000 组 × 10^9 允许合计 2×10^13），不进行浮点换算。

## 2. 缺省语义（不完整 ranking）

对票组 ranking `r`、权重 `w`：只有当候选对双方**都出现在** `r` 中时，该组才
对这一对贡献权重，排名靠前者获得全部 `w`；任一方缺失时该组对这一对**不贡献
给任一方**。缺失候选绝不解释成末位偏好、平票或弃权后仍计入。空 ranking 不表达
任何一对；相同 ranking 的不同票组各自贡献自己的 weight。
`unexpressed_weight = total_weight - a_over_b_weight - b_over_a_weight` 恒成立。

## 3. 实现选择：读入即累计表达候选对

采用**逐票组立即累计**方案：把候选按 ID 升序编号为 0..n-1，维护 n×n 整数矩阵
`matrix[i][j]`（`ordered[i]` 排在 `ordered[j]` 之前的权重）。每个票组只遍历其
ranking 实际表达的候选对（位置 `i<j` 的双重循环），把 `w` 加到 `matrix[idx[i]]
[idx[j]]`；相同 ranking 先按元组合并权重再一次性累计——`(w1+w2)` 与每组各自
贡献完全相等，且整数加法可交换，故输入顺序不影响结果。

- **完整矩阵**：输出阶段遍历全部 C(n,2) 个全局无序对（含双方均未表达的候选
  对），矩阵初始全零保证缺省对也有行；绝不会因候选数或票组数较小而省略。
- **每组每对一次**：ranking 组内无重复候选（校验保证），位置扫描 `i<j` 使每个
  无序对在一组内至多被触碰一次。
- **确定性**：合并与累计都是精确整数加法；candidates、comparisons、edges、
  分量均按 ID 升序输出；重排输入 candidates/ballots 不改变规范输出字节。
- **工作量**：与所有票组表达的对数总和成正比，最坏 20000×4950≈10^8 次整数
  加法（且 8 MB 输入上限实际排除了全满 ranking 的极端组合）；不为每个票组
  扫描或实例化全局候选对对象，不枚举候选排列或图路径。

## 4. 备选方案：先存名次再按全局对汇总

另一种可行方案是先为每个票组保存 `candidate -> 名次` 映射，再对每个全局无序对
`{a,b}` 扫描票组：仅当两侧名次都存在时比较名次累计权重。要避免缺省候选被当作
有偏好，关键是**名次缺失即跳过该组**，而不是把缺失当作末位名次参与比较。规模
控制上，可按候选建倒排（候选 → 含该候选的票组列表），对 `{a,b}` 只取两边票组
列表的交集扫描，使工作量与表达该对的票组数成正比，而不是 4950 对 × 20000 组的
全量扫描。两种方式都满足业务契约；本实现选择前者，因为其内层循环只触碰实际表达
的对，常数更小，且合并相同 ranking 后重复模式输入的工作量显著下降。

## 5. 由完整矩阵派生图、分量与胜者

矩阵、多数图、强连通分量与 Condorcet 结论来自**同一次分析的同一份已验证输入**，
且全部在读取所有票组之后推导：

- **严格多数图**：对每个无序对，仅当一侧表达权重严格大于另一侧时，从权重较高方
  指向较低方；相等（含双方为零）没有边。未表达权重、IRV 淘汰顺序与候选 ID 顺序
  均不产生边。所有候选都是节点，包括无入边/出边的孤立候选。
- **强连通分量**：在多数图上做逐源可达扫描（n≤100，精确且有界），互相可达的
  候选归为一个分量；分量内按 ID 升序，分量按各自最小 ID 升序；孤立候选单独成
  分量。不枚举图路径。
- **Condorcet winner**：唯一对每个其他候选都有直接出边的候选（出度恰为 n-1）；
  没有或有多个（理论上不可能，防御性处理）则为 null。单候选时该候选 vacuously
  满足条件。不得把强连通分量的顺序或 IRV winner 当作 Condorcet winner——
  IRV 胜者由逐轮淘汰规则产生，两两多数环（A>B、B>C、C>A）下 IRV 仍有胜者而
  Condorcet winner 为 null。
